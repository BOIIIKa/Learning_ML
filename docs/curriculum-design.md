## 2. 目录组织：按任务还是按三要素？

**结论：两者结合。主干目录按“学习范式 + 知识递进”排序，每一章内部固定用“模型–策略–算法”三要素拆解；三要素同时作为标签，供网站生成另外的索引视图。**

### 为什么不单纯按“监督 / 无监督”

- 优点是直观，与 ISL、李航两本书的大结构一致。
- 但它在前沿部分会失效。扩散模型、VAE、自监督学习从任务上看是“无监督”，训练时用的却是监督式损失。大模型的预训练是自监督，对齐阶段又属于强化学习。硬套任务分类会把真正的联系切断。
- 它也看不出“同一个思想在不同地方反复出现”。例如 ELBO 同时出现在 EM（第 11 章）、VAE（第 24 章）和扩散模型（第 25 章）。

### 为什么不单纯按“模型 / 策略 / 算法”

- 优点是严谨、抽象，正是科研需要的思维方式。李航第 1 章就是这个框架。
- 但如果拿它做一级目录，同一个算法会被拆散到三章里：SVM 的模型、合页损失和 SMO 各在一处。这样读者就失去了“一个算法从头到尾讲完”的体验，可视化也很难做成完整的故事。

### 混合方案的具体做法

1. **一级目录（9 个部分）** 按知识递进排序：数学预备 → 学习框架 → 经典监督 → 无监督与潜变量 → 深度学习基础 → 架构 → 生成模型 → 决策与大模型 → 科研方法。
   - 前半程基本对应“监督 / 无监督”，方便与原书对照。
   - 后半程按“深度学习的组成部分”组织，方便接上前沿。
2. **每一章的固定模板**：学习目标 → 三要素表 → 严谨推导 → 可视化组件 → 前沿跟进。三要素表让读者在每一章都练习同一种拆解方式。
3. **交叉索引视图**：每章带三类标签，分别是任务、策略（损失）和算法（优化 / 推断）。网站可以把目录切换成“按损失看全书”“按优化算法看全书”等视图。这些视图同时取代了李航第 12、22 章的“方法总结”。
4. **刻意设计的回链**：后面章节会显式回指前面的章节，帮助学生看到知识的统一性。例如：
   - LDA 与逻辑回归（05 → 04）
   - 核方法与 NTK（07 → 18）
   - EM 与 VAE 与扩散模型（11 → 24 → 25）
   - MCMC 与朗之万采样（13 → 25）
   - 三要素与大模型（01 → 27）

## 3. 数据与生成流程

- `curriculum/outline.yaml` 是**唯一数据源**。所有可读字段都是 `{zh, en}` 双语对象，前端直接读取它来切换语言、生成目录和交叉索引。
- `scripts/build_outline.py` 负责两件事：
  - **校验**：章节编号唯一；前置章节必须排在前面；标签合法；可视化组件 ID 唯一；双语字段齐全；三本书的每一章要么被引用、要么被明确列为“未纳入”并写明理由。
  - **生成**：输出 `OUTLINE.zh.md` 与 `OUTLINE.en.md`，供 GitHub 上直接阅读。
- 修改大纲后运行 `python3 scripts/build_outline.py`。`--check` 参数可以接入 CI，用来防止生成文件过期。

## 4. 双语写作规范

- 术语首次出现时附上另一种语言，例如中文写“证据下界（ELBO）”，英文写 “evidence lower bound (ELBO)”。
- 公式只写一份，用 LaTeX，中英版共用；数学符号与 UDL 附录 A 保持一致。
- 前沿文献统一使用英文原始引用，只翻译说明文字。
- 中英两版各自独立撰写，保证两边都自然、地道，而不是逐句互译。

<Slide lang="zh" part="method" title="期望风险与经验风险" say="先把“好”说清楚。">

<Step say="损失函数衡量一次预测的代价。">损失 $L(y, f(x))$：一次预测的代价</Step>

<Step say="期望风险是在整个分布上的平均损失。它才是真正的目标，但分布未知，算不出来。">期望风险 $R(f) = \mathbb E[L(Y, f(X))]$ ——真正的目标，但算不出来</Step>

<Step say="经验风险是在手头数据上的平均损失，这是能算的替代品。">经验风险 $\hat R_n(f) = \frac1n\sum_i L(y_i, f(x_i))$ ——能算的替代品</Step>

<Step say="最小化经验风险叫 ERM；再加一个复杂度惩罚，叫结构风险最小化 SRM。">ERM：$\min \hat R_n$ · SRM：$\min \hat R_n + \lambda J(f)$</Step>

</Slide>

<Slide lang="zh" part="method" title="三要素组合器" say="三要素可以自由组合，每一种组合都是一个学习算法。">

<Step say="常数模型配平方损失，得到的是平均数；配绝对值损失，得到的是中位数。">常数 + 平方 = 均值；常数 + 绝对值 = 中位数</Step>

<Step say="闭式解只适用于平方损失，其他损失要靠迭代。">闭式解只适用于平方损失</Step>

<Step say="右边自己组合试试，看看训练过程中经验风险怎样下降。">在右侧自由组合 →</Step>

<Slide lang="zh" part="math" title="平方损失下的最优预测" say="如果知道真实分布，最好的预测是什么？">

<Step say="固定 x，用常数 c 预测 Y。期望平方损失可以拆成两项：条件方差，加上均值与 c 的差的平方。">

$$
\mathbb E[(Y-c)^2\mid x] = \mathrm{Var}(Y\mid x) + (\mu(x) - c)^2
$$

</Step>

<Step say="第一项与 c 无关，是不可约噪声；第二项在 c 等于条件均值时为零。">⇒ $f^*(x) = \mathbb E[Y\mid X = x]$</Step>

<Step say="同理，绝对损失的最优预测是条件中位数。这就是两条线不同的原因：缺考学生拉低了均值，却几乎不影响中位数。">绝对损失 ⇒ 条件**中位数**</Step>

</Slide>

<Slide lang="zh" part="math" title="贝叶斯分类器" say="分类问题用 0-1 损失。">

<Step say="在每个 x 处，预测为 k 的期望损失是一减后验概率，所以应当选后验最大的类。">$f^*(x) = \arg\max_k\ p(x\mid k)\,P(k)$</Step>

<Step say="它的错误率叫贝叶斯错误率，是任何分类器都突破不了的下限。">贝叶斯错误率：任何分类器的下限</Step>

<Step say="右边拖动你的阈值：无论怎么拖，错误率都不会低于贝叶斯阈值处的值。">拖动阈值，永远低不过贝叶斯 →</Step>

<Slide lang="zh" part="math" title="经验风险能代替期望风险吗" say="对一个固定的函数，大数定律保证经验风险收敛到期望风险。">

<Step say="右边：用常数预测指数分布，损失取绝对值。紫色是期望风险，橙色是经验风险。">紫 = 期望风险，橙 = 经验风险 →</Step>

<Step say="样本少时，两者的最小点差得远；样本多时，经验风险最小化的解趋于最优解。">$n$ 增大 ⇒ ERM 的解 → 最优解</Step>

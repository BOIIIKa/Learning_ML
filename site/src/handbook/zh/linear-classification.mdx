### 常用代码

```python
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegressionCV, SGDClassifier

clf = make_pipeline(StandardScaler(),
                    LogisticRegressionCV(Cs=np.logspace(-3, 3, 13), cv=5, max_iter=2000))
clf.fit(X_train, y_train)
proba = clf.predict_proba(X_test)[:, 1]          # P(y = 1 | x)
flag = proba > threshold                          # 阈值按代价选，不一定是 0.5

# 数据很大或是流式的：平均 SGD，可以 partial_fit
sgd = make_pipeline(StandardScaler(), SGDClassifier(loss="log_loss", alpha=1e-4, average=True))
```

### 容易踩的坑

- **默认就有正则。** `LogisticRegression` 默认 `C=1.0`，即 L2 惩罚 $\frac{1}{2C}\|w\|^2$，并不是教科书里的纯极大似然。要做统计推断（标准误、p 值），用 statsmodels 的 `Logit`；只想要几乎无正则的拟合，就把 `C` 设得很大。
- **先缩放。** 惩罚和 lbfgs 的收敛都对尺度敏感。看到 `ConvergenceWarning`，先检查有没有放 `StandardScaler`，再考虑加大 `max_iter`。
- **完全可分会让系数爆炸。** 某个特征（或组合）完美区分两类时，无正则的 MLE 不存在，系数会非常大、标准误无穷。这往往是数据泄漏的信号，先查数据。
- **多分类**：lbfgs 等求解器默认拟合 softmax（多项逻辑回归），一组系数对应一个类别，`coef_` 的形状是 (类别数, 特征数)。
- **阈值是决策，不是模型的一部分。** 初筛时漏掉一个病人的代价远大于多叫一个人复查，阈值应按代价选（回顾第 01 章的贝叶斯决策）；类别不平衡时也可以用 `class_weight="balanced"`。在验证集上选阈值，不要在测试集上选。

### 读系数与概率

- $e^{w_j}$ 是**几率比**：其他特征不变时，$x_j$ 增加一个单位，几率乘以 $e^{w_j}$。标准化之后，“一个单位”就是一个标准差。
- 正则会把概率往 0.5 收缩。需要可靠的概率（例如给医生看风险）时，用 `CalibrationDisplay` 画可靠性曲线检查校准，必要时用 `CalibratedClassifierCV`。
- `SGDClassifier` 只有 `loss="log_loss"` 和 `"modified_huber"` 提供 `predict_proba`；合页损失（SVM）给的是分数，不是概率。

### 前沿阅读

- Soudry、Hoffer、Nacson、Gunasekar、Srebro（2018）：可分数据上梯度下降的隐式偏置——方向收敛到最大间隔。
- Ng 与 Jordan（2001）：判别模型与生成模型的比较，逻辑回归对朴素贝叶斯。
- Berger、Della Pietra、Della Pietra（1996）：自然语言处理中的最大熵方法，最大熵模型的经典来源。
- Freund 与 Schapire（1999）：用感知机做大间隔分类（投票/平均感知机）。
- Guo 等（2017）：现代神经网络的校准问题；温度缩放其实就是在 logit 上再拟合一个单参数的逻辑回归。

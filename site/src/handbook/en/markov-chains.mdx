### Go-to code

import numpy as np
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.decomposition import LatentDirichletAllocation

# Random-walk Metropolis: needs only the unnormalized log density
def metropolis(logp, x0, step, n, seed=0):
    rng = np.random.default_rng(seed)
    x, lp, out, acc = np.asarray(x0, float), logp(x0), [], 0
    for _ in range(n):
        y = x + step * rng.normal(size=x.shape)
        ly = logp(y)
        if np.log(rng.uniform()) < ly - lp:
            x, lp, acc = y, ly, acc + 1
        out.append(x)
    return np.array(out), acc / n

### Traps

- **Work on the log scale**: density ratios underflow easily; compare $\log u \lt \log\tilde\pi(x') - \log\tilde\pi(x)$.
- **Record rejections too**: a rejected step must repeat the current point, or the distribution is biased.
- **Trust diagnostics, not feelings**: run 4 chains from dispersed starts, require $\hat R \lt 1.01$, and report the effective sample size; read trace plots and autocorrelation plots together.
- **Prefer HMC to a hand-written random walk**: for Bayesian models with continuous parameters, use NUTS in Stan / PyMC / NumPyro.
- **PageRank on sparse matrices**: web graphs have hundreds of millions of nodes; power-iterate with `scipy.sparse`, add the dangling-node term separately, and never form the dense $G$.
- **LDA takes counts**: use `CountVectorizer` and drop stop words and very rare / very common words; choose the number of topics by perplexity or topic coherence, and in the end have a human read each topic's top words.
- **Topic labels are not stable**: different seeds give topics in a different order, sometimes with different content; align them before comparing.

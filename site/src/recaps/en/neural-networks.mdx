- **Shallow network**: $y = \phi_0 + \sum_d \phi_d\, a(\theta_{d0} + \theta_d^\top x)$ with the ReLU $a(z) = \max(0, z)$; each unit is a hinge that bends on the hyperplane $\theta_{d0} + \theta_d^\top x = 0$.
- **Piecewise linear**: with the on/off pattern fixed the network is linear; a ReLU network cuts input space into linear regions that join continuously.
- **One input**: $D$ units give at most $D + 1$ pieces; conversely any broken line on $[a, b]$ is exactly a ReLU network whose output weights are the slope changes at the kinks.
- **Two inputs**: $D$ lines in general position make at most $1 + D + \binom{D}{2}$ regions; with $D_i$ inputs, $\sum_{j \le D_i} \binom{D}{j}$.
- **Universal approximation**: one hidden layer suffices to approximate any continuous function on a closed interval uniformly; for an $L$-Lipschitz function, $D$ evenly spaced units give error $\le Lh/2$. It does not say how many units (exponentially many in high dimension), how to train, or whether it generalizes.
- **Depth as folding**: the tent map $t(x) = 2\max(0, x) - 4\max(0, x - \tfrac12)$ stacked $L$ times has $2^L$ pieces with $6L + 1$ parameters; a shallow net with the same parameters has at most $2L + 1$ pieces and falls behind from $L = 3$.
- **Example**: $1 + 2\,\mathrm{ReLU}(x) - 3\,\mathrm{ReLU}(x - 1) + 2\,\mathrm{ReLU}(x - 2)$ takes the values $1, 3, 2, 3$ at $0, 1, 2, 3$, with slopes $0, 2, -1, 1$.
- **Parameters**: width $W$ and depth $K$ give $(D_i + 1)W + (K - 1)(W + 1)W + (W + 1)D_o$ parameters.

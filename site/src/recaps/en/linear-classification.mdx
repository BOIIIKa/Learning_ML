- **Perceptron**: $f(x) = \mathrm{sign}(w^\top x + b)$; whenever $y_i(w^\top x_i + b) \le 0$, update $w \leftarrow w + \eta y_i x_i$, $b \leftarrow b + \eta y_i$. The loss is the (unnormalized) total distance of misclassified points to the hyperplane.
- **Dual form**: $w = \sum_i \alpha_i y_i x_i$ with $\alpha_i = \eta \times$ the number of updates on point $i$; only inner products (the Gram matrix) are needed → kernel methods.
- **Novikoff**: on separable data with margin $\gamma$ and radius $R$ (augmented space), at most $(R/\gamma)^2$ updates, independent of $\eta$ and the dimension; on non-separable data it never stops (pocket, averaged perceptron). The solution depends on the start and the order.
- **Logistic regression**: $P(Y=1\mid x) = \sigma(w^\top x + b)$, linear log-odds; maximum likelihood = minimum cross-entropy = $\sum_i \log(1 + e^{-y_i f(x_i)})$.
- **Gradient and Hessian**: $\nabla\ell = \hat X^\top(y - p)$, $\nabla^2\ell = -\hat X^\top S\hat X$ with $S = \mathrm{diag}(p(1-p))$ ⇒ concave; Newton = IRLS, converges in a few steps.
- **Separable data**: no MLE, $\|w\| \to \infty$; add L2 (scikit-learn's default `C=1`). Unregularized gradient descent drifts towards the max-margin direction.
- **Maximum entropy**: the entropy-maximizing model under feature-expectation constraints is $P_w(y\mid x) \propto \exp(\sum_k w_k f_k(x,y))$, and its dual is the log-likelihood; $f_{j,c} = x_j\mathbb 1[y=c]$ gives the softmax, which is the sigmoid for two classes.
- **Losses of the margin** $m = yf(x)$: perceptron $\max(0,-m)$, cross-entropy $\log(1+e^{-m})$, hinge $\max(0,1-m)$, exponential $e^{-m}$; the gradients all read "prediction minus truth". Worked example: $(1,3),(4,1)$ against $(1,0)$, 6 updates to $w = (1,4)$, $b = -2$, $\alpha = (1,1,4)$.

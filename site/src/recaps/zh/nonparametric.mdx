- **kNN 的三要素**：模型是局部平均（训练集本身就是模型），策略是邻域内的多数表决 / 均值，算法是找邻居。三个设计选择：距离（L1 / L2 / L∞，先标准化）、k（小 k 低偏差高方差，用交叉验证选）、决策规则。
- **Cover–Hart**：$R^* \le R_{1\text{NN}} \le 2R^*(1-R^*) \le 2R^*$；$k\to\infty$、$k/n\to0$ 时 kNN 一致。
- **kd 树**：交替坐标、中位数切分，建树 $O(n\log n)$；搜索先下到叶子，回溯时分割线到 $q$ 的距离 $\ge r$ 就整棵剪掉，低维下平均 $O(\log n)$。
- **维数灾难**：外壳体积占比 $1-(1-\varepsilon)^d\to1$；圈住比例 $p$ 的数据需要边长 $p^{1/d}$；距离的相对波动 $\sqrt{7/(5d)}\to0$，最近 / 最远距离之比趋于 1。
- **基函数扩展**：$f(x)=\sum_m\beta_m h_m(x)$ 对 $\beta$ 线性，最小二乘照用。$M$ 次样条、$K$ 个节点的自由度为 $M+1+K$（三次 $K+4$，自然三次 $K$）。
- **平滑样条与 GAM**：$\min\sum(y_i-f(x_i))^2+\lambda\int f''^2$ 的解是自然三次样条，$\hat\beta=(N^\top N+\lambda\Omega)^{-1}N^\top y$；有效自由度 $\operatorname{tr}S$（kNN 为 $n/k$）。GAM：$f=\alpha+\sum_j f_j(x_j)$，用回溯拟合或一次岭回归求解。

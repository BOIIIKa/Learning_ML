- **差距**：训练误差随复杂度单调下降，测试误差呈 U 形。两者之差 $R(\hat f) - \hat R_n(\hat f)$ 是泛化差距。
- **偏差–方差**：期望测试误差 = $\sigma^2$ + 偏差² + 方差。模型越丰富，偏差越小、方差越大；两者描述的都是换训练集时整个过程的表现。
- **乐观度**：最小二乘有 $\mathbb E[\text{训练}] = \sigma^2(1 - p/n)$、$\mathbb E[\text{测试}] = \sigma^2(1 + p/n)$。$C_p$ 与 AIC 把差距 $2p\sigma^2/n$ 加回去。
- **一致界**：有限假设空间 $R(\hat f) \le \hat R_n(\hat f) + \sqrt{(\ln M + \ln(2/\delta))/(2n)}$，即差距 ≈ √(容量 / n)。
- **估计测试误差**：留出法（训练 / 验证 / 测试）；k 折 CV，常用 $k = 5$ 或 $10$；LOO，线性平滑器可直接算 $\frac1n\sum(e_i/(1-H_{ii}))^2$；自助法，每次约 36.8% 的点袋外。
- **规范**：所有依赖数据的步骤都放进 CV 循环（`Pipeline`）；调参又要报告时用嵌套 CV；样本不独立时用分组或按时间的划分。
- **双下降**：越过插值阈值 $p = n$ 后，最小范数解可能再次泛化变好。参数个数不等于容量。

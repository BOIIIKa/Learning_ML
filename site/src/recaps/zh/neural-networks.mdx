- **浅层网络**：$y = \phi_0 + \sum_d \phi_d\, a(\theta_{d0} + \theta_d^\top x)$，ReLU $a(z) = \max(0, z)$；每个单元是在超平面 $\theta_{d0} + \theta_d^\top x = 0$ 处拐弯的“铰链”。
- **分段线性**：开关组合固定时网络是线性函数；ReLU 网络把输入空间切成线性区域，块与块连续相接。
- **一维**：$D$ 个单元至多 $D + 1$ 段；反之 $[a, b]$ 上任何折线都能精确写成 ReLU 网络，输出权重 = 拐点处的斜率改变量。
- **二维**：$D$ 条一般位置的直线至多切出 $1 + D + \binom{D}{2}$ 个区域；$D_i$ 维时为 $\sum_{j \le D_i} \binom{D}{j}$。
- **万能逼近**：单隐层足以一致逼近闭区间上的任何连续函数；$L$-Lipschitz 时 $D$ 个等距单元误差 $\le Lh/2$。但它不说要多少单元（高维时指数多）、怎么训练、能否泛化。
- **深度即折叠**：帐篷函数 $t(x) = 2\max(0, x) - 4\max(0, x - \tfrac12)$ 叠 $L$ 层得 $2^L$ 段，参数 $6L + 1$；同参数浅网络至多 $2L + 1$ 段，$L \ge 3$ 起落后。
- **例题**：$1 + 2\,\mathrm{ReLU}(x) - 3\,\mathrm{ReLU}(x - 1) + 2\,\mathrm{ReLU}(x - 2)$ 在 $0, 1, 2, 3$ 处取 $1, 3, 2, 3$，斜率 $0, 2, -1, 1$。
- **参数**：宽 $W$、深 $K$ 的网络有 $(D_i + 1)W + (K - 1)(W + 1)W + (W + 1)D_o$ 个参数。

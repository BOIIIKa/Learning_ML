- **配方**：选输出分布 $\Pr(y \mid \theta)$ → 网络输出参数 $\theta = f(x; \phi)$ → 最小化 $-\sum_i \log \Pr(y_i \mid f(x_i; \phi))$。
- **高斯 ⇒ 平方损失**：$\frac{(y - \mu)^2}{2\sigma^2} + \log \sigma + $ 常数；拉普拉斯 ⇒ 绝对值损失（中位数，稳健）。
- **伯努利 ⇒ 二元交叉熵**：$\ell = \log(1 + e^f) - yf$，梯度 $\sigma(f) - y$；用 `logaddexp` 计算才稳定。
- **分类分布 ⇒ softmax 交叉熵**：$\ell = \log\sum_k e^{f_k} - f_y$，梯度 $p - e_y$；泊松 ⇒ $e^f - yf + \log y!$。
- **同一个梯度**：典范连接下梯度总是“预测均值 − 观测”。
- **异方差回归**：同时输出 $\mu$ 和 $\log\sigma$；最优 $\sigma^2$ = 残差平方；带子随噪声变宽，覆盖率两端都接近 95%。
- **交叉熵 = 熵 + KL**：$H(p, q) = H(p) + \mathrm{KL}(p\|q)$，$\mathrm{KL} \ge 0$（Jensen）；最大似然 = 最小化到经验分布的 KL。
- **例题**：$f = 2$ 时 BCE 为 $0.1269 / 2.1269$；logits $(2, 1, 0)$ 的 CE 为 $0.4076$；$r = 8$ 时 $\sigma = 8$ 最优（$3.498$）；$\mathrm{KL}(0.7\|0.5) = 0.082$。
